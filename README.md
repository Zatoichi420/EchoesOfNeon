# Echoes of Neon (Accessible Tactical Cyber-Noir FPS)

An accessible-first, single-player tactical cyber-noir First-Person Shooter developed for Unity 6 / Unity 2022+ with the Universal Render Pipeline (URP).

## 🚀 Quickstart for Developers

1. **Open in Unity:**
   - Launch Unity Hub.
   - Click **Add Project from Disk** and select this directory (`EchoesOfNeon`).
   - Open using **Unity 6** or **Unity 2022.3+ LTS** with the **Universal Render Pipeline (URP)** template.
2. **Package Dependencies:**
   - Unity Input System (`com.unity.inputsystem`)
   - Universal Render Pipeline (`com.unity.render-pipelines.universal`)
   - TextMeshPro (`com.unity.textmeshpro`)
3. **Documentation:**
   - See [`MEMORY.md`](./MEMORY.md) for full game lore, architecture diagrams, accessibility mechanics, and the active roadmap.
