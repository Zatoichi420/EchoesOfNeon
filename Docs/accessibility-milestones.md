# Accessibility milestones

Source: 2026-10-07 multi-agent review of the repo against Unity's accessibility manual
(https://docs.unity3d.com/6000.5/Documentation/Manual/accessibility/_index.html).
Work in sets of three; after each set, stop and playtest before starting the next.

## Milestone 1: make it honest, testable, pausable
1. **Wire or hide stubbed settings.** Colorblind mode and high-contrast outlines drive the
   sound compass. Settings with no system behind them (screen shake, aim assist, subtitles,
   audio description, SFX/dialogue volume) are hidden from the menu until they work.
   `AccessibilityManager.UnimplementedSettings` is the single list; an EditMode test fails
   if a setting is neither consumed nor listed there.
2. **Test framework.** `EchoesOfNeon.Runtime` asmdef, `Assets/Tests/EditMode`, tests for
   the settings audit and for AccessibleButton/Toggle/Slider node create/remove balance.
3. **Real pause menu.** Time stops, Resume / Main Menu / Quit, spoken "Paused" and
   "Resumed", focus lands on Resume, Neural Dilate cannot fight the pause.

**Test gate:** open the game, press Escape (pause), navigate with arrows + VoiceOver,
resume; check the Accessibility tab no longer shows dead controls; run EditMode tests.

## Milestone 2: speech and structure (BUILT 2026-10-07, awaiting playtest)
4. Menu focus speech (`MenuFocusAnnouncer`) + macOS `say` fallback (`SpeechFallback`) when no screen reader is running.
5. TextMeshPro-aware labels, Back/dismiss action, hints, panel headers, selected state.
6. Status + repeat keys: `H` reads `StatusRegistry` providers (tactical: Neural Dilate/sonar, Cookie's state and distance; the side-scroller keeps its own Status); new `V` "RepeatLast" says the last announcement again. No health/ammo/objective exist in the tactical scenes yet, so none are read. Announcement priority queue deferred.

## Milestone 3: audio and captions (BUILT 2026-10-08, awaiting playtest)
7. SFX and dialogue volume applied to every audio source via `AudioRouting.Bind` (barks = Dialogue, everything else = SFX; master multiplies both); Mono Audio toggle switches the engine speaker mode.
8. `CaptionService` + `CaptionDisplay`: Subtitles (enemy barks, with direction) and Sound Captions ("[Gunfire, to your left]", off by default, rate-limited). A test fails if a recorded bark has no transcript. Audio Description stays hidden: no cutscenes exist.
9. UI size 100/125/150% for captions and the pause menu (`UiScaleApplier`). NOT the main menu: its layout is absolute-positioned for 1920x1080 and would clip; needs layout groups. Nothing else in the game is color-coded, so no further palettes.

## Milestone 4: controls and onboarding (BUILT 2026-10-08, awaiting playtest)
10. Rebind W/A/S/D individually (`Move:Up` etc.); Toggle Neural Dilate; side-scroller sprint/crouch now honor the existing toggle options; Timing Assist (Standard/Relaxed/Generous: longer enemy wind-ups and fend window). Key Bindings tab is two columns and shows each current key as a spoken hint.
11. Difficulty (Story 0.4x / Easy 0.7x / Normal / Hard 1.3x damage taken) in the side-scroller. Tactical scenes have no player health yet, so it does nothing there.
12. `F1` reads your current controls from live bindings; first-run spoken welcome (once for the menu, once for gameplay). NOT built: an interactive practice tutorial.

## Later / platform
Hook `screenReaderStatusChanged` and `nodeFocusChanged`; OS caption/font-scale settings on
iOS/Android builds; haptics toggle; rename our `AccessibilitySettings` to avoid clashing
with `UnityEngine.Accessibility.AccessibilitySettings`.

## Milestone 2 playtest gate
- Main menu: arrow keys move focus and each stop is spoken ("Options, button"). Watch for double speech if VoiceOver is on (focus announcement plus VoiceOver's own).
- Options: opens as "Options. Controller, tab, selected"; switching tabs says the tab and which is selected; Escape / gamepad B goes back, focus returns to Options.
- Pause (Escape in a gameplay scene): "Paused. Resume, button".
- Tactical scene: `H` reads Neural Dilate/sonar/Cookie; `V` repeats the last announcement. (New `RepeatLast` is not yet in the keybinding menu: the menu is generated by `MainMenuUISetup`; regenerate to add it.)

## Milestone 3 playtest gate
- Options > Audio: SFX, Dialogue and Mono Audio rows exist; lowering SFX quiets footsteps/abilities but not guard barks; Mono puts everything in both ears.
- Options > Accessibility: no gaps where dead rows used to be; Subtitles, Sound Captions, size slider present.
- In a tactical scene with a guard: barks show as `Guard (to your left): "Contact! Get eyes on him!"`; with Sound Captions on, gunfire shows `[Gunfire, ahead]`.
- Size 150%: captions and pause menu larger. Check the pause title is not clipped.

## Milestone 4 playtest gate
- Key Bindings tab: 24 rows in two columns, all on screen; Rebind Move Up then press a key; WASD still moves if you rebind one.
- Controller tab: Toggle Neural Dilate (press once on, again off).
- Side-scroller: Toggle Sprint / Crouch now work there. Difficulty Story: hits hurt 40 percent as much. Timing Assist Generous: enemy attack sounds start noticeably earlier.
- Fresh profile: spoken welcome at the menu, and again once in a gameplay scene; `F1` reads the controls.
