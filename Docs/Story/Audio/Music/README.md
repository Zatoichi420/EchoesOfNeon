# Echoes of Neon — Music Sketches

Two compositional sketches, generated 2026-09-14 in response to Orlando's "yes generate
the ambient stuff and make the midi files." These are **MIDI sketches for Orlando to open
in GarageBand and assign real instruments to**, not final production audio and not
something Unity plays directly. They exist so a mood/tempo/key idea is on the table to
react to, not as an answer to the still-open "does music play during exploration"
question in `../audio-intake-form.md` — both pieces are offered as options for whichever
answer that question eventually gets.

Both were written from scratch with a minimal custom Standard MIDI File (SMF) writer
(no `mido`/`midiutil` — neither was installed, and adding a dependency for a one-off
script wasn't worth it). Independently verified after generation with three separate
tools that don't share code with the writer: `file` (confirms valid SMF format-1
header), macOS `qlmanage`'s own MIDI thumbnailer (confirms the event stream parses), and
a from-scratch verification parser that checks every note-on has a matching note-off.
All three passed clean on both files, no mismatches.

## `theme_new_carthage.mid`

Slow, sparse exploration theme. 62 BPM, A minor, 16-bar loop, 4 tracks (Pad, Bass,
Melody on a Rhodes-style GM patch). Harmonic-minor-flavored i–VI–III–V progression, the
classic noir turnaround. Deliberately thin and quiet-feeling — per the blueprint's own
audio-first principle, a blind player navigates by the game's spatial sound cues, so
this is written to sit underneath them, not compete for attention.

## `tension_pursuit.mid`

Driving chase/combat cue. 138 BPM, same A-minor family as the theme (this is meant to
sound like what the theme becomes under threat), 8-bar loop, 4 tracks (Bass Ostinato,
String Stabs, Stinger Accent). The ostinato is a root-root-fifth-root eighth-note pulse;
the string stabs land on off-beats using plain dissonant intervals (minor 2nd + tritone)
since General MIDI can't perform a real tremolo. Two "stinger" hits at bars 1 and 5 are
positioned as a possible separate cue point for an "enemy spotted you" moment, matching
the existing accessibility announcement for that beat in `Docs/action-mapping.md`.

## What this doesn't decide

- Whether music plays at all during exploration (see `audio-intake-form.md` Music Q1)
- Final instrumentation — GM program numbers were chosen for clarity while sketching,
  not as a production instrument choice
- Whether the two pieces should crossfade into each other live (theme → pursuit) or are
  two independent, separately-triggered cues

## Source

Generated by `../generation-scripts/midiwriter.py` (from-scratch SMF writer) and
`../generation-scripts/compose_midi.py` (the actual composition). Re-run
`python3 compose_midi.py` from that folder to regenerate both files, or edit the chord
progressions / instrument choices there directly. `../generation-scripts/verify_midi.py`
is the independent checker used to validate the output — run it against any regenerated
file as `python3 verify_midi.py <file>.mid`.
