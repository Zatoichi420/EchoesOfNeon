# Echoes of Neon: Script

Scene scripts, written by the writer's room and confirmed by Orlando scene by scene. Source of truth for canon is [[Story Canon Log]]. Orlando records Marcus; every other voice is cast from the heritage plan.

## Format (every script note)
- Filename: `Act N - Scene NN - Title.md`. Header: Scene ID, Act, Mission, Location, Cast with heritage and accent notes, Status (DRAFT / CONFIRMED).
- Blocks, in order of play: SOUND (layered, with at least three orientation landmarks a blind player can navigate by), MUSIC, ACTION (what the player does, accessible, no visual-only cues), LINE blocks, PUZZLE blocks (three hint tiers, no failure that ends a scene), CLUE blocks.
- LINE format: `CHARACTER (voice note): line` then `[PERF] note for the voice actor`. Marcus lines are tagged (Orlando).
- Tags: [SAFE] works before the reveals; [POST] only after; [PLANT: clue and payoff]; [AUDIO-ONLY] if no visual equivalent is needed.
- Every scene ends with a Guardrail Check: no "twin" or "vampire" before the reveal; Marcus unaware; Cookie only reacts to what she witnessed; no em-dashes or en-dashes; each cue has an audio equivalent.
